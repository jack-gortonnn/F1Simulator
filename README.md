# F1 Simulator

F1 Simulator is a text-based qualifying-and-race simulator made in 2022 in Python.

It features a 20-driver dictionary with all of the tracks from the 2022 F1 Season.

This was my first project with Python and I'm happy with how well the text-based I/O has held up.
